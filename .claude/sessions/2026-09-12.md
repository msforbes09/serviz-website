## Decisions

- Scope is a public marketing site. No auth, no admin, no backend API client, no
  database. Content is typed data in the repo.
- Designs and the brand palette come later. Nothing invents copy or colour until
  they arrive.
- Working rules, engineering principles and a trimmed security checklist were
  adapted from the egov-api workspace into `CLAUDE.md`.

## Gotchas hit

- **Base UI composes with `render`, not `asChild`.** `<Button asChild>` fails
  type checking.
- **`new Date()` in a Server Component fails the build** under Cache Components.
  The footer year uses `"use cache"` with `cacheLife("days")`.
- **`vitest.config` must be `.mts`** — `package.json` has no `"type": "module"`,
  so Vite's native loader treats a `.ts` config as CommonJS.
- `lib/utils.ts` re-exports `cn` from the `cn` package, which current shadcn
  installs. It is not the old clsx plus tailwind-merge helper.
